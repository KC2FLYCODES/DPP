# Garment models

Drop GLB files here named by silhouette and they become the studio default for every design:

- `tee.glb`
- `longsleeve.glb`
- `crewneck.glb`
- `hoodie.glb`

Front of the garment should face +Z (glTF default); use "Facing" in 3D Studio if it doesn't. Any scale is fine; the studio normalises to the selected fit. Baked normal / AO maps (folds, seams) are kept; color, washes, distressing and prints are applied by the studio.
Per-design overrides: 3D Studio → Piece → Upload GLB.
Only commit models we hold a commercial licence for.
